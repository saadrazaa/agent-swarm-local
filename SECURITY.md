# Security Policy

Report a vulnerability in **this deployment configuration** (Compose file, scripts,
docs — anything in this repo) privately via
[GitHub private security advisories](https://github.com/saadrazaa/agent-swarm-local/security/advisories/new),
not a public issue.

Vulnerabilities in **Agent Swarm, agent-fs, or MinIO themselves** belong upstream —
report those to the respective project. This repo only pins and configures them.

This is a single-maintainer hobby repo with no SLA. Expect best-effort response.
